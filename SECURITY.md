# Security Policy

## Supported version

Security fixes are applied to the current `v3.0` branch.

## Reporting a vulnerability

Please do not publish credentials, private keys, client configurations, or an
unfixed vulnerability in a public issue. Report security problems through
[GitHub private vulnerability reporting](https://github.com/ikhak-dev/amneziawg-vds-manager/security/advisories/new).

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. You can expect an initial response within seven days.
